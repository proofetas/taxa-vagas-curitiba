# Taxa - Vagas Temporárias em Curitiba

Plataforma para conexão entre candidatos e empregadores para vagas temporárias em Curitiba/PR.

## Funcionalidades

- ✅ Cadastro e login de usuários (candidato/empregador)
- ✅ Publicação de vagas (empregador)
- ✅ Busca de vagas por título, local ou empresa
- ✅ Favoritar vagas (candidato)
- ✅ Candidatura via WhatsApp
- ✅ Dark mode
- ✅ Perfil com foto e currículo (candidato)
- ✅ Perfil da empresa (empregador)

## Tecnologias utilizadas

- HTML5
- CSS3 (com variáveis e Dark Mode)
- JavaScript (puro)
- LocalStorage (persistência de dados)
- Font Awesome (ícones)

## Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Cadastre-se e comece a usar!
